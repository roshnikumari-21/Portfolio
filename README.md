# Roshni Kumari - Cyberpunk Portfolio 💻✨

Welcome to my personal portfolio! This project is a complete UI/UX overhaul featuring a **Cyberpunk / Neo-Tokyo Hacker aesthetic**. Built using Next.js, and styled with vanilla CSS/Tailwind to provide an immersive, high-fidelity experience.

### 🔗 Live Preview (Cyberpunk Theme)
[Click here to view the live Vercel deployment!](https://cyberpunk.roshnikumari.online/)

---

## 🚀 Features

- **Neo-Tokyo Aesthetic:** Deep obsidian black, dark charcoal, and striking neon accents (Electric Pink, Cyan, and Neon Purple).
- **Interactive Cyber Elements:** Glitching text, animated CRT scanlines, a glowing grid matrix, and harsh angular shape languages (CSS clip-paths).
- **Cybernetic Audio Terminal:** Included a synthwave music/audio module featuring internet radio streams and pseudo tracks.
- **Secure Uplink Contact Form:** A beautifully crafted form mimicking an encrypted peer-to-peer transmission terminal with input glow effects.
- **Dynamic Animations:** Real-time data terminal overlays, scrolling text, and holographic visualizers!

## ⚙️ Tech Stack
- **Framework:** Next.js (React)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & Custom CSS properties
- **Deployment:** Vercel

## 🛠️ Getting Started Locally

First, install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to initiate the mainframe.
